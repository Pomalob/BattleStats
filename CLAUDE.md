# StatsBattle — заметки для Claude Code

FastAPI + PostgreSQL, разбор реплеев «Мира Танков». Общее описание — в [README.md](README.md).

## Команды

```bash
pytest                                  # тесты без базы
docker compose up -d db                 # Postgres для интеграционных тестов
TEST_DATABASE_URL=postgresql://battlestats:battlestats@localhost:5432/battlestats pytest
uvicorn src.app:app --reload            # локальный запуск (нужен DATABASE_URL)
docker compose up --build               # приложение + локальный Postgres
```

`TEST_DATABASE_URL` очищается между тестами — только одноразовая база.

## Устройство

- `src/config.py` читает окружение **на импорте** и падает при старте, если в проде
  нет нормального `SECRET_KEY`. Тесты, которым нужно другое окружение, перезагружают модуль
  через `importlib.reload` и возвращают его обратно фикстурой.
- `src/app.py` импортирует функции базы по именам, поэтому тесты подменяют их
  через `monkeypatch.setattr(app_module, ...)` — см. `tests/conftest.py`.
- Соединения берутся из пула (`database.get_conn()`), который коммитит на выходе
  и возвращает соединение обратно. Не открывай `psycopg2.connect` напрямую.
- Парсер работает с байтами (`parse_replay_bytes`); загруженные файлы никогда
  не попадают на диск.

## Правила

- Ники игроков, названия карт и танков приходят из файлов реплеев — в HTML только
  через `esc()`. Внутри страниц нет инлайновых `onclick` с подстановкой данных,
  используется делегирование по `data-*`.
- Бои общие между пользователями, а владение — через `user_battles`. Удаление
  отвязывает бой от пользователя и удаляет строку, только когда владельцев не осталось.
- Скрытие игрока (`hidden_players`) — это фильтр в аналитике конкретного пользователя,
  а не удаление данных. Не заменяй его на `DELETE`.
- Всё, что приходит от клиента в `/api/battles/save`, пересобирается в `_clean_battle`:
  в SQL попадают только известные поля с приведёнными типами.
- Изменения схемы — идемпотентным `_DDL` плюс `_run_migration` для того,
  что нельзя выразить через `CREATE TABLE IF NOT EXISTS`.
- `result` боя вычисляется на сервере из `winner_team` и `player_team` (`_battle_result`),
  а не берётся из запроса. Не возвращай доверие к клиентскому полю.
- Реплей без блока результатов помечается `complete=False`. Такие бои не сохраняются
  и не участвуют в сводке — иначе они добавляют ничью и нулевую строку каждому игроку.
- Если команда игрока не нашлась в метаданных, она ищется в блоке результатов
  (`_team_from_results`): анонимайзер ников ломает совпадение по имени, а команда 0
  тихо превращает каждый бой в поражение.
- Имена пользователей уникальны без учёта регистра — уникальный индекс по `lower(username)`.
- Расширенные поля реплея лежат в JSONB `details` (бой и игрок) и `user_battles.recorder`.
  Какие поля берутся — списки `*_FIELDS` в `replay_parser.py`; `_clean_battle` пропускает
  только их. Добавляешь поле — добавь в список, иначе сервер его выбросит при сохранении.
- `recorder` — на `user_battles`, а не на `battles`: у одного боя разные записавшие.
- Бой без `details` (сохранён старой версией) получает их при повторной загрузке реплея
  (`_backfill_details`), а не через миграцию: исходных файлов на сервере нет.

## Что важно знать про формат реплеев

Проверено на 300 настоящих файлах клиента 1.45:

- `dateTime` в реплее — `DD.MM.YYYY HH:MM:SS`. Колонка `date_time` текстовая и сортируется
  как текст, поэтому парсер приводит дату к `YYYY-MM-DD` (`_normalise_date`). Не убирай это:
  иначе 31 августа окажется позже 8 сентября во всех сортировках и в диапазоне дат.
- В метаданных есть `mapDisplayName` с готовым русским названием — его и используем.
  `MAP_NAMES` остался только как запасной вариант.
- Ники в блоке результатов анонимизированы для команды противника: `name` — подставной,
  настоящий лежит в `results.players[accountDBID].realName` (`_real_names`). Это ещё и держит
  `battle_hash` стабильным: два игрока одного боя видят разные подставные имена.
- `meta.vehicles` содержит только свою команду. Полный состав — в блоке результатов.
- Около трети реплеев в папке идут одним блоком, без результатов боя.
